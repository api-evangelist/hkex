# HKEX

> HKEX (Hong Kong Exchanges and Clearing Limited) operates the Stock Exchange of Hong Kong, the Hong Kong Futures Exchange, their clearing houses, and the London Metal Exchange. Its market data is sold through licensed binary multicast datafeeds (Orion Market Data platform) and a historical-data storefront (HKEX Data Marketplace, delivered by SFTP/cloud/download). Its one documented RESTful JSON API is the FINI API Gateway for IPO settlement, restricted to registered market participants using OAuth 2.0 JWT-bearer credentials — the API guide itself is a public PDF.

Generated by API Evangelist from the apis.yml catalog and repo artifacts; HKEX publishes no llms.txt of its own.

## APIs

- [HKEX Orion Market Data Platform - Securities Market (OMD-C)](https://www.hkex.com.hk/Services/Market-Data-Services/Infrastructure/HKEX-Orion-Market-Data-Platform-Securities-Market-OMD-C?sc_lang=en): Real-time securities datafeeds in a proprietary binary format over IP multicast/UDP; licensed, not HTTP. Binary interface spec: https://www.hkex.com.hk/eng/prod/dataprod/Documents/HKEX_OMD-C_Binary_Interface_Specifications_v1.39b.pdf
- [HKEX Orion Market Data Platform - Derivatives Market (OMD-D)](https://www.hkex.com.hk/Services/Market-Data-Services/Infrastructure/HKEX-Orion-Market-Data-Platform-Derivatives-Market-OMD-D?sc_lang=en): Real-time futures/options datafeeds, binary over multicast; licensed. Developers guide: https://www.hkex.com.hk/-/media/HKEX-Market/Services/Market-Data-Services/Infrastructure/HKEX-Orion-Market-Data-Platform-Derivatives-Market-OMD-D/HKEX-OMDD-Developers-Guide-v1,-d-,26.pdf
- [HKEX Data Marketplace Historical Data](https://data.hkex.com.hk/catalog): Historical full order book tick data, CCASS shareholding data, and securities attribute files; delivered via SFTP, cloud-to-cloud, or download — no REST API.
- [HKEX FINI API](https://www.hkex.com.hk/Services/Platform-Services/FINI?sc_lang=en): RESTful JSON endpoints for IPO workflows — GET /api/ipos/list/v1, GET /api/ipos/refdata/v1, POST /api/eipo/subscriptions/{add|change|invalidate|query}/v1, POST /api/eipo/funding/{confirm|query}/v1, GET /api/crypto/meta. OAuth 2.0 JWT-bearer (RS256 G1/G2 JWTs) against https://openam.connect.hkex.com.hk; participants only. User guide: https://www.hkex.com.hk/-/media/HKEX-Market/Services/Next-Generation-Post-Trade-Programme/Fini/FINI-API-User-Guide-v0,-d-,41.pdf
